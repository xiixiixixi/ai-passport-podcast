# 收听与资料保存

在硬件上选节目和单集，节目库顶部的最近播放也可上下选中，按确定继续听；正在播时直接回到当前播放页。确定键暂停或续播；播放页上键加音量、下键减音量，长按任意方向键进入调进度；进入后，上键后退、下键前进，短按调整15秒、长按调整60秒。按确定应用新进度，长按确定取消。长按确定打开收听选项和连接设置。操作提示简短、按场景出现，避免长期占用一排按钮说明。

网页可以搜索订阅、添加链接、看最近收听、进度、统计，以及管理设备。节目和单集列表会标注已经缓存的数量或状态。滚动条隐藏后仍可正常滚动。

新增订阅的封面会由后台自动准备成小图，再传到硬件的节目库和播放页，不需要手动保存图片或重新编译。后台保留已准备的封面；封面地址变化时重新准备。硬件只临时保存当前可见的少量图片，优先保证声音；网络慢或图片暂未就绪时先显示备用图，稍后自动补上。没有提供封面的节目仍使用备用图。

后台的 `/api/health`（运行状态接口）显示当前代码版本及摘要，可以据此确认正在运行的版本。仅更新时间或换网页缓存，不能证明后台程序已升级。

后台启动立即刷新订阅，默认每三小时再刷新，并按最新在前的顺序提前准备每档最新三集，准备完成的文件保留复用。第一次听未缓存单集时，后台先把整集准备并校验完成，再允许开始播放；完成缓存以后不会每次重新转码。点播任务优先于等待中的自动缓存，有一个专供点播的准备位置；已经执行中的任务不会被强行中断。网页显示预计等待时间，它会受源站速度、节目长度和排队情况影响。当前硬件只显示“准备音频”，尚未显示网页的预计分钟数。播放时，硬件边接收音频边用小容量缓冲连续输出。硬件收听时，后台必须保持运行。

在网页“添加节目 → 管理已订阅”的缓存管理面板，可以选择每档自动缓存1、3、5或10集，清理时至少保留1、3、5、10或30集，并查看缓存集数、占用、磁盘剩余和上次清理结果。设置保存在后台资料目录，重启或更新容器后保留。默认自动缓存三集、清理至少保留三集。

后台每天北京时间凌晨3:10自动清理。普通清理会保留每档最新指定数量的单集，并保护仍活跃的播放会话、未听完的单集、近十四天听过的单集，以及正在排队或准备的任务。清理后磁盘空闲仍低于默认16吉字节时，会再执行一轮只保每档最新一集的收缩清理；上述保护仍有效。“立即清理”按同一规则运行。

“清空全部缓存”需要再次确认，只清除音频缓存，保留订阅、授权和收听进度；当前活跃会话以及排队、准备中的单集暂时保留。它与普通清理不同，会删除其他未听完单集的音频文件，下一次收听需要重新准备。缓存清理不会使资料目录备份失去必要性。

`server/data/`（资料目录）保存订阅、收听记录和授权，`server/media/`（音频目录）保存缓存。正常重启容器和再次运行安装脚本会保留这两个目录。完整备份前先停止服务，再复制两目录，并单独私密保存 `server/.env`（安装配置）。在自己的服务器恢复三者，可以保留设备授权。音频缓存可重新准备；丢失资料目录会丢失进度和授权。

暂停后续播会先补发本机已听进度，再检查其他设备是否更新了位置。暂时同步失败时，当前这集沿用本机位置和收听记录；已经排队的记录保留，恢复连接后再补发。停止后的最后一小段声音也会完整记入，重复发送不会重复计时。

共享范围是一户家庭。授权设备共享这户的节目与历史，不同家庭分别安装。移除设备会阻止之后访问，历史保留；网页退出登录不会退出硬件。忘记管理口令的恢复方法见[后台说明](../server/README.zh_CN.md)。

正在收听时，设置、节目库或列表页7秒无操作会回到正在播放的这集，不读取旧进度或重启音频。设置第一项“回到播放”可以直接退出，长按确定也可以返回。调进度草稿不会因自动返回而被提交。

默认15秒无操作关闭背光并停止页面重绘，声音、联网与进度保存继续。“立即息屏”可以手动关闭。按任意键的第一整个动作只唤醒，下一次按键才操作；亮屏后显示实时进度。这里只息屏，不进入系统休眠，实际续航增加量尚未测量。
