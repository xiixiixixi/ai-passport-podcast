# 播客字库源文件

`NotoSansSC-Regular.otf` 是两个应用字库使用的常规字重 Noto Sans SC 源字体。文件内嵌版权为 © 2014–2021 Adobe，内嵌许可声明为 SIL Open Font License 1.1（开放字体许可证）。字体家族上游为 [Noto CJK](https://github.com/notofonts/noto-cjk)，参见[许可条款](https://openfontlicense.org/open-font-license-official-text/)。保留文件的 SHA-256（文件校验值）为 `faa6c9df652116dde789d351359f3d7e5d2285a2b2a1f04a2d7244df706d5ea9`；它标识本地源文件，不声称与上游最新文件完全一致。

用 `lv_font_conv`（字体转换器）1.5.3 执行 `python3 tools/generate_podcast_fonts.py`。脚本校验源文件，生成4位灰度、无字距调整的字库；18像素标题字库随后使用本项目按字形编码的无损字节压缩，16像素界面字库保持未压缩：

- `main/app_cjk_18.c`：18像素、23像素行高；可打印 ASCII（基础西文）、Latin-1（常见西文字母）、基本汉字、扩展A、指定中文标点，以及 `title-symbols.txt` 中十个实际标题缺字。用于动态节目名与单集标题。
- `main/app_ui_16.c`：16像素、20像素行高；基础西文和 `ui-symbols.txt` 中的固定应用文案。用于提示、日期、说明和固定错误消息。字符清单排除凭据定义。

请求范围内，源字体含20,976个基本汉字、6,582个扩展A字形。未覆盖的扩展字、表情和其他文字仍显示可见占位；不声称支持任意 Unicode（字符编码标准）。本产品移除未使用的历史16像素生成字库；保留带许可的源字体，仍可重新生成。

启动检查读取代表字形描述符与实际位图，核对预期 FNV（字节校验算法）值 `6296d092`，并检查一个已知不支持的表情确实不被误报为支持。检查成功不能证明实体屏幕输出。构建 `tools/podcast_preview`，在可写目录运行预演程序，可检查真实控件的字体覆盖、软件绘制和24KiB（24千字节）界面内存池预算。示例标题是排版测试内容，不是真机画面记录。

2026-10-04 的字符回归样本取自现有十一档节目共3,728集、设备可显示的标题前缀，只保存字符集合。最初四档节目核查发现七个源字体已有但未编入的字符 `ǎι〇のん︱｜`；十一档核查额外发现 `≠` 影响一集、`⚠` 影响一集、`～` 影响两集。这三个字符均有实际源字形，仅补齐它们，不扩大整个 Unicode（字符编码标准）区块。界面把粗乘号 `✖` 显示为普通文字 `×`，不为不占字符宽度的表情样式选择符单独绘制方框，并将富文本对象占位明确显示为 `[图]`。原始元数据和书签保留，其他未知字符继续显示占位并记录。将 `tests/fixtures/podcast-title-characters.txt` 作为预演程序参数，可用实际控件和 A8（8位灰度）解码检查全部2,813种实际字符；发布配置的主机预演也保持运行断言。

启动时另经真实位图回调解码代表字形，并把中文绘制到临时 RGB565（屏幕像素格式）画布，预期 A8 校验值为 `6be31a46`、屏幕像素校验值为 `b704ea88`。临时内存在界面和网络启动前释放。实际标签检查记录缺字码点、非法中文编码、透明文本和错误字体绑定，不输出标题。这些检查用于区分软件各阶段，仍不构成实体屏幕验收。

自定义解码保留字形尺寸、字符映射和全部16级灰度。完整对比核验27,782个字形描述和8,409,616个解码灰度像素，75张播放页预演图逐像素相同。这与 LVGL（界面库）标准的三位压缩字体功能不同。通过锁定版本转换器执行 `python3 tools/generate_podcast_fonts.py --title-only` 可重现；`tests/test_podcast_font_lossless.c`（完整字形对比程序）可传入转换器的原始源文件完成穷举比较。
