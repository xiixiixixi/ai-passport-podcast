# 随身听后台

这是供一户自行安装的后台：运行在自己的电脑、家庭服务器或 NAS（网络存储主机），网页和获得授权的播客机共享这一户的订阅、最近收听和播放进度。不同家庭分别安装自己的后台；本版没有集中托管的多用户云服务。

面向使用者的完整安装入口见工程根目录说明。安装脚本会准备本目录的 `.env`（本地安装配置）、生成一次性安装码，并启动 `compose.yaml`（容器组合配置）。无需修改程序或填写播客平台密钥。

## 第一次使用

1. 启动后台并打开安装脚本给出的首次设置网页。安装码通过网址片段带入，页面立即清除片段，服务器访问日志不会收到安装码。
2. 设置至少 10 个字符的管理口令。首次设置完成后，安装码不能再次覆盖管理员设置。
3. 打开「我的设备」，生成一个配对码。
4. 硬件播放页长按确定，进入「连接设置」。初装硬件会直接进入设置页。
5. 手机连接硬件屏幕显示的热点与密码，手动打开 `http://192.168.4.1`；输入家里的无线网络、后台地址及六位配对码。
6. 硬件显示连接成功并进入节目库。以后正常开机即可收听，无需重复配对。

后台地址必须是硬件能够访问的局域网地址。`localhost`（本机地址）或 `127.0.0.1` 只能由运行后台的那台电脑使用。可以通过安装配置中的 `PODCAST_PUBLIC_URL`（设备可访问的后台地址）固定正确地址；路由器为后台主机保留固定地址后，日常使用更省事。

## 已有节目和资料

默认保留 11 档节目，网页可通过苹果播客公开目录搜索，或粘贴节目订阅／小宇宙链接添加。内置小宇宙公开页面转换不再依赖作者的家庭地址。

`data/` 保存节目目录、动态订阅、共享收听记录和授权资料；`media/` 保存准备好的音频。这两个目录由组合启动配置挂载在容器外，重启或更新容器不会重新创建资料库。请不要把它们上传到公开仓库，也不要用删除数据卷的命令进行日常重启。

网页退出登录只取消这个网页登录，不影响硬件。移除设备会撤销该设备的权限，原收听记录仍保留。多台获得授权的硬件共享同一户的节目和进度；设备不会强行切走另一端正在播放的节目。

更新旧安装前，请备份 `data/` 和 `media/`，并安排新硬件程序与配对一起更新。公共版后台默认要求登录和配对；旧的无凭据硬件程序不能直接访问保护后的后台。

## 找回管理口令

在自己的后台主机、工程目录中执行：

```sh
docker compose --env-file server/.env -f server/compose.yaml exec podcast python manage_access.py reset-admin --confirm
```

然后重新运行安装脚本，打开首次设置页并设置新口令。恢复工具仅取消管理口令和已有网页登录；设备权限、订阅、音频缓存、收听进度和统计均保留。

## 配对接口约定

管理员通过 `POST /api/devices/pairings`（生成配对码接口）领取一个 10 分钟内有效的六位码。只有最新生成的码有效，并且只能由一台设备消费。接口有持久限速和事务保护。

硬件调用 `POST /api/devices/claim`（设备配对接口）：

```json
{"code":"六位数字字符串","device_id":"硬件已有的持久 device- 编号","name":"可选设备名称"}
```

成功响应只包含同一 `device_id`（设备编号）与 64 位小写十六进制 `token`（设备凭据）。响应有明确长度，设备应验证长度、字符与编号后保存。之后所有目录、播放、进度同步及音频请求，通过 `Authorization: Bearer`（请求头中的设备凭据）授权；包括 `HEAD`（只取响应头）与带 `Range`（所需音频区间）的请求。凭据不放在网址里。

配对新凭据先等待设备保存。首次使用新凭据时，后台在一个事务中使其生效并废掉旧凭据。设备保存失败或在保存前断电，原来可用的凭据仍有效；安全保存的新凭据不会因为短时配对码过期而失效。重新申请会覆盖上一个待生效凭据。管理员移除设备会同时废止当前与待生效凭据，并且不能被并发连接恢复。

后台只保存凭据、配对码和网页登录凭据的哈希（不可直接用于登录的摘要），管理口令使用加盐密码哈希。设备列表不回显任何凭据。设备只能以自己的编号建立播放记录，并且只能写入属于自己的播放记录；编辑来源和管理设备只允许管理网页。

本版提供家庭局域网安装；管理口令和配对机制不等于互联网托管服务。需要从外网使用时，应另行配置安全的加密访问通道，不应直接公开家庭服务端口。

## 检查

```sh
python -m unittest discover -s tests -v
```

测试在临时目录中运行，包含真实生成的音频、断点音频读取、持久收听记录、原子配对、权限撤销、设备归属和重启恢复。旧音频行为检查只在明确的隔离测试实例中绕过授权；正常服务没有兼容绕过入口。
