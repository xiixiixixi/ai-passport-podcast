# 准备公开发布

用 ESP-IDF（乐鑫开发工具）5.5.3完成固件完整检查和后台测试，再把成功检查实际输出的归档目录交给 `python3 scripts/export-release.py --archive 已核验的归档目录 --output dist/public-preview` 生成公开包。命令中的“已核验的归档目录”须替换为本次构建的真实路径，不能沿用旧版本。工具核对固件身份，生成升级清单，排除私人和运行资料；导出本身不会上传或烧入设备。

上传 GitHub（代码托管网站）时，使用导出的源码包，或按同样的公开文件范围整理工程。不要上传 `.env`（私人配置）、`.local/`（本机安装入口）、后台资料、音频缓存、编译和下载依赖目录、串口与设备识别记录、家庭服务器配置、内部修复报告或清理备份。导出后复核清单和校验值，再上传源码、公开安装说明及所需固件文件。公开后台默认要求管理网页登录与硬件配对。

## 提交前的公开文件检查

`.local/`（本机材料目录）只保存本地私密清单、制作材料、检查记录和备份，不能加入源码或下载包。私人配置、后台资料、音频缓存、原始节目封面、设备二维码、内部报告和构建产物也已加入忽略范围。

在准备提交的仓库里运行一次 `python3 scripts/install-git-hooks.py`（启用提交检查）。以后正常提交时，检查读取实际暂存的文件和内容；即使使用强制添加，内部文件和敏感内容仍会被拒绝。已有自定义钩子保留原逻辑。

`.github/public-files.json`（公开文件清单）记录经确认可以公开的文件。新增加的必要代码或说明，应先检查内容和许可，再把项目相对路径加入清单，并与文件一起暂存。不要把整个工作目录或所有未跟踪文件自动登记为公开文件。四份内部目录说明必须使用导出的公开替换版，固件文档不能带内部图片引用。

提交前可以运行 `python3 scripts/check-public-commit.py --all`（检查完整暂存清单）。远程检查也运行同一道保护。原始开发工程中保留内部材料时，使用整理后的公开源码副本提交；遇到拦截应修正文件范围和内容。

[官方媒体作品列表](https://ai-passport.folotoy.cn/plays/?category=media)里既有独立作品，也有需要后台的作品。它们分别说明网络和服务授权；只烧入硬件程序不能替用户部署本项目后台。

官方公开发布说明要求：从零地址安装的完整固件、文件不超过设备八兆字节容量、3:4封面、中英文名称、介绍和安装步骤，可附公开的加密网页源码链接，提交后审核。**没有登录核验私有发布表单，具体私有字段和账号权限仍未验证。**[官方网页刷机工具](https://ai-passport.folotoy.cn/tools/web-flasher/)支持完整或分段文件，但这不能证明旧身份迁移或升级保留资料。

发布说明必须区分首次安装和只更新应用，解释后台依赖、支持布局及未完成的实机验收。正式审核要求与实际支持范围不一致时，应明确标为兼容设备预览版，不用未验证的通用安装承诺补齐。源码检查、电脑预演图和播放日志不能写成首次安装已通过、实机照片或耳听验收；当前证据见[检查记录](validation.zh_CN.md)。

建议作品名称：**随身听**；英文名 Pocket Podcast（口袋播客）。介绍：自家后台管理的播客库，白底刻度尺播放页，支持中文标题、最近收听及共享进度；一次性配对授权自己的硬件。后台默认提前准备每档最新三集，网页可以调整缓存和清理。每户自行安装后台，固件不附带公共音频服务、真实收听资料或他人的设备凭据。

重新构建时，请使用成功检查实际输出的归档路径；不同机器或构建可能得到不同校验值。发布包的清单绑定实际固件文件，源码发布版本应与对应构建来源一致。保留对应调试归档和公开包后，可以移除生成的编译文件。
