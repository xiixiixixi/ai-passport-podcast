# 播客机连接设置与配对

公开固件不带任何家庭无线网络名称、密码或固定后台地址。每户运行自己的后台；一个后台可以授权多台设备，设备共用订阅节目和收听进度，各自保留独立的播放记录身份。

## 第一次连接

1. 安装并打开自己的后台，在“设备”页面生成六位配对码。配对码十分钟有效，只能使用一次。
2. 开启播客机。未保存连接设置时，屏幕会显示临时热点 `Podcast-xxxx`（播客设置热点）、随机的十六位热点密码和 `http://192.168.4.1`（设备本地设置页）。热点使用 WPA2（无线加密）。
3. 手机连接这个热点，手动打开屏幕上的本地地址。手机此时不需要通过这个热点上网。
4. 填写自己的 2.4 GHz（吉赫兹）无线网络、密码、后台根地址和配对码。后台地址填写服务器的局域网地址，或有可信证书的 HTTPS（加密网址）域名；localhost（本机）和回环地址指的是播客机自己，不能使用。
5. 提交一次，等待设备实际验证网络并完成配对。全部成功后才保存，随后重启进入原有节目库并关闭设置热点；手机可以切回平时的无线网络。

后台地址最多一百六十字节，不包含页面路径、内嵌用户名密码、查询参数或片段。开放网络的密码可以留空，其他网络密码为八至六十三字节。网络名称最多三十二字节，中文名称能容纳的字数更少。加密后台连接使用正常可信证书检查，并等待网络校时；校时被阻断或证书不可信会显示连接失败，不会绕过验证。

## 更换或恢复连接

在播放页长按确定，选择操作菜单最后一项“连接设置”。设备先保存收听位置，再重启进入相同的临时设置页，此次启动不同时开启声音任务。节目库为空或配对失效时，长按确定可以进入连接设置，不会因没有可播放节目而无法设置。

重新配对前，先在后台生成新码。无线网络密码错误、配对码无效、后台不可达或保存失败都不会替换原设置。已有设置时，在设置页长按确定可以取消并重启返回原播放器。普通断网只会重新连接，不会自动打开设置热点。更换连接不清除书签或尚未同步的收听记录。

## 身份、保存与请求

配对沿用现有 `podcast_sync`（收听同步存储）中长期保存的 `device-*`（设备同步身份），不会每次重启重新生成，也不把 MAC（网卡标识）当作秘密凭证。配对请求为 `POST /api/devices/claim`（提交设备配对），内容包括配对码和设备身份；程序严格检查返回身份是否相同、凭证是否为六十四位小写十六进制，随后将带版本和校验的连接记录保存到独立 `podcast_cfg`（连接配置存储）区域。

目录、音频准备、收听记录以及全部音频 HEAD/GET（音频信息／内容请求）都携带 `Authorization: Bearer`（授权请求头）凭证。凭证不出现在网址或诊断输出中；带凭证的请求不自动跳往其他地址。后台在保存后的新凭证第一次使用时才替换原凭证，因此本地保存失败不会让旧设置悄悄失效。后台管理员可以撤销设备；401/403（授权失效／权限不符）会提示重新连接，不自动清除配置。

设置服务只供一台手机使用，限制填写内容和响应大小，并临时运行；这次启动尚未开启声音任务。测试网络时只使用 RAM（运行内存）配置，验证成功后才保存应用记录。退出先停掉网页回调，再释放其队列和锁；如果停止失败，保留仍被使用的资源，等待安全停止或设备重启。

## 验证范围

电脑检查运行真实的配置保存、控制器、音频请求创建和设置流程，只替换设备及网络边界。真实界面程序预演检查设置页的字形、画面边界，并在二十四千字节的界面内存池中反复创建和删除。这些检查不等于实体手机和硬件验证；仍需实测手机加入加密热点、获得地址、访问路由器、加密后台校时与证书、首次配对、错误密码重试、重启保留设置、取消、撤销及播放。

固件安装与官方恢复系统兼容，是连接设置之外的验证事项。详见[公开固件与永久恢复协议](podcast-recovery.zh_CN.md)。使用本次发布中经核验的安装文件和分区说明；完成这里的设置功能，本身不代表已经兼容官方小程序安装。
