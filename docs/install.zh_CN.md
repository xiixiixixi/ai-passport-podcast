# 安装与绑定

## 安装后为什么原来的界面会变

本项目的硬件程序是一套独立玩法，安装后会替换设备正在运行的玩法。厂商[玩法页面](https://ai-passport.folotoy.cn/plays/65/)也明确说明“安装会覆盖当前设备的玩法”：电脑使用 Chrome（谷歌浏览器）或 Edge（微软浏览器），把设备开机、用数据线连接，选择设备并等待写入和重启。网页通过 USB（电脑数据连接）写程序，不要求原来的身份卡界面仍在运行。

**能用厂商网页写程序，不等于本项目的任意安装包都适合这台设备。**本公开包面向下文的现代恢复布局。只有普通保存区、无线参数区和主程序的旧布局，没有现代永久恢复系统；在旧布局上更新过应用，不能证明本公开包适合首次安装。首次安装、保留资料的升级和恢复出厂程序，要分别选择对应方法。

## 先启动后台

安装并启动 Docker（容器运行工具），然后运行工程根目录对应系统的安装脚本。第一次会下载程序环境、依赖和音频转换工具，需要能访问互联网，比以后的启动更久。脚本生成每户独立的安装码、启动后台、检查是否就绪，并生成 `.local/first-setup.html`（本机首次设置页）。打开它，设置至少十个字符的管理口令。这份本地页面和 `server/.env`（私人安装配置）不要发给别人。

正常后台地址是 `http://服务器局域网地址:8899`。安装脚本会尝试识别局域网地址，请在“我的设备”中确认。`127.0.0.1`（本机地址）只能在后台电脑上用，硬件不能填它。苹果电脑或Linux（类Unix系统）可以运行 `bash scripts/install-server.sh --public-url http://服务器局域网地址:8899` 指定地址；Windows（微软系统）脚本使用 `-PublicUrl`（后台地址参数）。建议在路由器中给后台主机保留固定地址。硬件使用2.4GHz无线网络。

再次运行安装脚本会沿用原安装码、端口和资料。旧后台升级到要求授权的新版本时，硬件也需要新程序和配对；不要只升级后台，导致旧硬件无法访问。

部分服务器的容器代理只监听主机本地地址，会阻止普通构建网络下载依赖。支持的系统可用 `PODCAST_BUILD_NETWORK=host`（构建时使用主机网络）解决；后台运行仍使用普通组合网络。不同容器平台有所区别，安装失败会明确报告。

后台默认直接访问节目源。如果网络必须经过代理，在私人 `server/.env`（安装配置）中填写 `PODCAST_HTTP_PROXY`、`PODCAST_HTTPS_PROXY`（后台访问代理），地址必须能从普通容器访问，不能照抄主机本机地址。构建时下载依赖的代理与日常抓节目的代理分别配置。

新安装先出现节目目录，再完成整集音频准备。公开源码预置十一档节目；后续订阅数量由每户自行添加和移除。默认启动即抓取，随后每三小时刷新，并按从新到旧的顺序提前准备每档最新三集。网页“添加节目”中的缓存管理可以调整自动缓存和清理保留集数；详情见[收听与资料保存](use.zh_CN.md)。一小时硬件音频约115兆字节，另有原始和网页音频；请为订阅数量留足存储空间。完成的缓存会复用。

公开源码后台默认要求管理网页登录和硬件配对。已安装的家庭后台、个人调试配置和真实收听资料不属于公开安装包。

安装脚本记录当前系统账号，让后台以同一身份读写私密资料目录。之后请用原安装账号再次启动；换账号或运行身份配置异常时，脚本会停止，不覆盖资料或自动改变归属。

## 硬件：先分清安装和升级

本版现代布局有六个区：设置、无线参数、主程序、资料、连接配置和永久恢复程序；主程序从 `0x10000` 开始，恢复程序从 `0x6C0000` 开始，实际应用不超过六兆字节。安全升级工具还要求设备已有有效的永久恢复程序；分区表相同并不足够。

- **已经是现代布局，永久恢复功能正常：**先安装 Python（程序运行工具）3.10或更新版本，在解压后的安装包目录运行 `python3 -m pip install -r scripts/flash-requirements.txt` 安装依赖，再运行 `python3 scripts/flash-device.py --manifest release/manifest.json`。微软系统将上述两条命令的 `python3` 改成 `py`。明确选择连接端口，工具核验芯片、容量、文件、分区、恢复程序和未完成安装记录后才请求确认。它只更新主程序并回读核对，不清除设置，不改分区、厂商身份或恢复程序。打开USB（通用串行总线）连接可能重启设备。
- **通过已有兼容手机安装器首次安装播客：**设备须已初始化兼容的永久恢复系统，只上传 `FoloToy-AI-Passport-full.bin`（从零地址写入的完整固件）。已核查的现代手机安装器可能清除普通应用资料，之后需要重新设置和配对；不能把它当作保留进度的升级。手机安装不会写入包中的启动程序，按键恢复仍依赖设备已有的启动程序。
- **旧布局或恢复程序不明：**本工程安全工具拒绝安装。它没有初始化永久恢复或迁移旧身份的功能，也不会用全片擦除绕过问题。先采用与具体设备相符、经过验证的厂家或社区恢复基线。官方网页刷机工具支持完整或分段文件，但本工程未验证它保留旧身份的算法，不能默认身份会保留。

`FoloToy-AI-Passport.bin`（只有应用的文件）绝不能写在零地址。通用完整包包含启动程序、分区表和播客主程序，但不含永久恢复程序；预留恢复位置不会自动产生恢复功能。不要把它从零地址直接写入未知布局的设备来绕过检查。本版尚未提供面向所有出厂设备、可保留厂商身份的首次初始化流程。详细兼容依据见[固件恢复说明](../firmware/docs/podcast-recovery.zh_CN.md)。

## 绑定一次，以后直接用

登录网页，在“我的设备”生成配对码。只有最新六位码有效，十分钟内可绑定一台设备。硬件首次启动显示临时加密热点和密码；手机连接后手动打开 `http://192.168.4.1`，填写无线网络、后台地址和配对码。如果手机自动改用移动网络，先关闭这一功能。

真正连接和配对成功后才保存。失败保留旧配置。播放页长按确定可重新设置。在后台可以改设备名称或撤销授权；撤销不会删除收听资料。

## 换回厂商的出厂身份卡

厂商提供了[恢复出厂固件指南](https://ai-passport.folotoy.cn/guides/restore-factory-firmware/)，与播客的后台配对、现代安装器的按键恢复是三件不同的事：

1. 用手机扫描**自己设备背面**的二维码，打开设备专属网页。
2. 把完整链接私密地转到自己的电脑，用桌面版 Chrome（谷歌浏览器）或 Edge（微软浏览器）打开。链接含 SN（设备编号）和 KEY（设备密钥），不要公开上传或发给他人。
3. 用支持数据传输的 Type-C（通用串行总线接口）线连接设备和电脑，并让设备开机。
4. 在专属网页底部点击“恢复默认固件”，再点击“连接并核对设备”。选择名称包含 `USB JTAG/serial debug unit`（芯片的电脑连接接口）的设备；核对无误后按厂商页面确认并执行完整恢复。
5. 等待页面完成下载、校验、写入和自动重启，再拔线。之后在厂商微信小程序重新连接并同步身份卡内容。

这是厂商公开说明的恢复路径；本项目没有实际执行过这次恢复，也没有验证专属页面的身份校验与资料迁移算法。恢复可能清除硬件上的播客设置和未同步进度；保留自己的后台资料，可以保留已同步的收听历史，以后重装播客时重新配对。

设备能正常开机、电脑能识别 USB（电脑连接接口）时，更换应用界面本身不会挡住这条刷机入口。乐鑫[芯片说明](https://docs.espressif.com/projects/esp-idf/en/v5.5.3/esp32c3/api-guides/usb-serial-jtag-console.html)确认该接口能使芯片进入下载模式；若列表为空，先唤醒设备、核对数据线、端口和其他串口程序占用，再按厂商支持指引处理。不要把上键当成芯片下载按键，也不要为恢复而先擦除整台设备。

## 当前还需验证什么

公开包需要分别完成后台首次设置、手机连接硬件热点、配对、实体按键进入恢复，以及连续播放的实机验收。已有设备的启动与播放记录、电脑自动检查和独立后台验收，只能证明各自检查的链路；不能代替首次安装、耳听音质或恢复入口测试。已完成与仍待验证的项目见[检查记录](validation.zh_CN.md)，不能宣称适用于所有设备的一键安装已经验证。
