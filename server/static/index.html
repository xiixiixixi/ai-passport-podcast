怎么找到节目地址？

01

苹果播客

进入一档节目的主页，点分享，再复制链接。请复制节目主页，不要复制某一集。

https://podcasts.apple.com/cn/podcast/id1552904790

例如「商业就是这样」的苹果播客主页。

02

小宇宙

进入播客主页，点分享，再复制链接。地址里应当有 /podcast/；带 /episode/ 的是单集链接。

https://www.xiaoyuzhoufm.com/podcast/5e4ee557418a84a0466737b7

例如「忽左忽右」的播客主页。 使用公开节目内容，付费或登录后才可听的内容可能无法导入。

03

RSS（播客订阅）地址

如果节目官网提供“订阅”或“RSS（播客订阅）”，复制它的地址。有的地址以 .xml 结尾，有的没有；它需要是一份播客订阅内容。

https://feed.xyzfm.space/example.xml

这是格式示例。只有后台成功读到节目和单集后，才会允许确认添加。

这页用苹果播客公开目录搜索节目，并支持地址导入，没有自动推荐。添加后，新单集会由后台定期更新；播放进度与设备共用。

我的设备

把家里的播客机连接到这份节目库。

每台设备配对一次，之后开机自动连接。多台设备与网页共享这户的订阅和收听进度；退出网页登录不影响已经配对的硬件。

连接一台播客机

硬件与后台需要连到同一个家庭网络。

  1. 在硬件播放页长按确定，选择「连接设置」。首次安装会直接进入设置。
  2. 手机连接屏幕显示的热点和密码，手动打开 http://192.168.4.1。
  3. 填入家里的无线网络、这里的后台地址和配对码。连接成功后，硬件会进入节目库。

使用硬件能访问的局域网地址。后台地址变化后，需要重新连接设置。
